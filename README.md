## 触发方式
在OpenClaw聊天框输入关键词：芮小丹、小丹、天国的女儿、天道，即可自动触发角色。

## 使用说明
1. 无需修改任何文件，直接将整个ruixiaodan-skill文件夹放入OpenClaw的skills目录。
2. 重启OpenClaw即可加载，聊天时触发关键词，AI自动切换为芮小丹人设。
3. 知识库包含芮小丹经典对话、语录，确保语气、思维与角色高度一致。

1. 角色说话干净利落、真诚坦荡，符合芮小丹"清醒独立"的特质。
